# OmniRef 快捷键与操作

快捷键在画布获得焦点时生效；点击画布即可把焦点从搜索框或属性输入框移回画布。

## 全局

| 操作 | 快捷键 |
|---|---|
| 显示或隐藏 OmniRef | `Ctrl+Alt+Space` |
| 窗口置顶 | 顶栏“置顶” |
| 退出进程 | 顶栏“退出”或托盘菜单“退出” |

若全局热键已被其他程序占用，OmniRef 会在启动时提示，应用仍可从托盘显示。

## 画布导航

| 操作 | 鼠标或快捷键 |
|---|---|
| 围绕光标缩放 | 鼠标滚轮 |
| 平移 | 按住空格拖动，或中键拖动 |
| 重置视口为 100% | `Ctrl+0`，或点击底部缩放百分比 |
| 缩放范围 | 10%–800% |

## 创建和编辑

| 操作 | 鼠标或快捷键 |
|---|---|
| 添加文本 | `T` |
| 添加分组框 | `F` |
| 打开文件、文件夹或网址 | 双击卡片 |
| 编辑文本 | 双击文本卡片 |
| 保存文本编辑 | `Ctrl+Enter`，或点击编辑框外 |
| 取消文本编辑 | `Esc` |
| 粘贴 | `Ctrl+V` |
| 复制选中卡片 | `Ctrl+C` |

可以直接把文件、文件夹、图片或文本拖到画布。剪贴板位图会作为 PNG 内嵌；HTTP/HTTPS 文本会成为网址卡片。

## 选择和排列

| 操作 | 鼠标或快捷键 |
|---|---|
| 单选 | 点击卡片 |
| 增减选区 | `Ctrl` + 点击 |
| 框选 | 在空白区域拖动 |
| 追加框选 | `Ctrl` + 在空白区域拖动 |
| 全选 | `Ctrl+A` |
| 删除卡片 | `Delete` 或 `Backspace` |
| 移动 1 个画布单位 | 方向键 |
| 移动 10 个画布单位 | `Shift` + 方向键 |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |

拖动选中卡片右下角可调整尺寸。图片默认保持比例；按住 `Shift` 可自由调整宽高。命令栏“排列”菜单提供六种对齐、水平/垂直分布以及四种层级操作。

分组框不能嵌套。把卡片移动到分组框内会建立归属；移动分组框时，其中的卡片会一起移动。
